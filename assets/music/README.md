# Music

Drop your own licensed background tracks here (e.g. `assets/music/lofi_calm.mp3`) and reference
them from a project's `music.track` field. This directory is gitignored except for this file —
music licensing varies per track, so tracks themselves should never be committed to the repo.

Good royalty-free sources: YouTube Audio Library, Pixabay Music, Epidemic Sound (paid), or your
own recordings. Keep a note of each track's license/source somewhere outside this repo.
